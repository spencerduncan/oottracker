# Project64 Setup Guide for OoTMM Tracker

> **Note:** Standard Project64 JavaScript scripting is no longer supported.
> For Project64 users, we recommend using **Project64-EM** with the Lua tracker script.
> See the [Project64-EM Setup Guide](PROJECT64_EM_SETUP.md) for instructions.

## Alternatives

### BizHawk (Recommended)
BizHawk provides the most robust auto-tracking experience:
- Cross-platform (Windows, Linux, Mac)
- Full-featured ExternalTools support
- See [BizHawk Setup Guide](BIZHAWK_SETUP.md)

### Project64-EM
Project64-EM is OoTMM's modified emulator with Lua scripting support:
- Uses `assets/oottracker-pj64em-base.lua`
- See [Project64-EM Setup Guide](PROJECT64_EM_SETUP.md)
